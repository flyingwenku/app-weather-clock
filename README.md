# 桌面天气时钟（app-weather-clock）

把旧手机变成桌面时钟：横屏、全屏、常亮，七段数码管风格数字 + 室外天气 + 室内温湿度。

## 界面

```
┌────────────────────────────────────────────────────────────────┐
│   ██ ██ : ██ ██ : ██ ██      ☀  26.3°C      🌡 28.5°C          │
│   数码管时钟（红/蓝）         晴  湿度 60%     湿度 --          │
│                              室外             室内（电池）      │
│  ────────────────────────────────────────────────────────────  │
│  10月25日 星期六 · 北京                            更新 23:40   │
└────────────────────────────────────────────────────────────────┘
```

点底部城市名进入设置：搜索城市、切换数字颜色（红 / 蓝）。

## 设计要点

| 决策 | 选择 | 理由 |
|---|---|---|
| 天气数据源 | **Open-Meteo（免 API Key）** | 不用注册、不用保管密钥；换国内源只需改 `WeatherRepository` |
| 城市 → 经纬度 | Open-Meteo 地理编码 | **不需要定位权限**，旧手机体验更好 |
| 数码管数字 | **Canvas 自绘七段** | 不引入字体文件，颜色/发光完全可控 |
| minSdk | **21**（Android 5.0） | 面向旧手机 |
| 依赖 | **仅 `androidx.core-ktx`** | 不用 AppCompat / Material：编译快、体积小、老机器跑得动 |
| 网络 / JSON | `HttpURLConnection` + `org.json` | 均内置，不引第三方库 |
| 常亮 | `FLAG_KEEP_SCREEN_ON` | 无需任何权限（仅前台有效，锁屏自动释放） |

## 室内温湿度的现实约束

- **室内温度**用电池温度代理：待机时通常比室温高 2~5 °C，**充电时会高 5~10 °C**。界面如实标注「室内（电池）」，不伪造数值。若机型带 `TYPE_AMBIENT_TEMPERATURE` 传感器则以其为准。
- **室内湿度**：有 `TYPE_RELATIVE_HUMIDITY` 传感器才显示，绝大多数手机没有，显示 `--`。

## 构建

GitHub Actions 云端构建（`.github/workflows/android-build.yml`）——环境层与 `app-phone-monitor` 共用同一套流水线：

```bash
git push origin main          # 自动触发
gh run watch                  # 看进度
gh run download               # 下载 apk
```

技术栈：JDK 17 / Gradle 8.9 / AGP 8.7.3 / Kotlin 2.0.21 / compileSdk 35 / minSdk 21。

## 已知限制

- 断网时室外数据显示 `--`，并在恢复后自动重试
- Android 8 以下设备使用 vector 图标（已在 `mipmap-anydpi` 提供回退）
- 常亮仅在 app 前台有效，锁屏后系统会熄屏（Android 安全设计）
